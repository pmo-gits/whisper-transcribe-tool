WHISPER VIDEO TRANSCRIBER - QUICK START GUIDE
==============================================

FIRST TIME SETUP (RUN ONCE WITH INTERNET)
----------------------------------------
1. Open this folder in VS Code.
2. Open Terminal in VS Code (Ctrl + ~).
3. Run the setup script for your Operating System:

   Windows:  .\setup.bat
   macOS:    chmod +x setup.sh && ./setup.sh

This will automatically create a local virtual environment (.venv) 
and install the Whisper libraries on your laptop.


HOW TO TRANSCRIBE YOUR VIDEOS
-----------------------------
Copy your video files (.mp4, .mkv, .mov, etc.) into this folder or subfolders.

1. SEE THE LIST OF YOUR VIDEOS
   Windows:  .\.venv\Scripts\python transcribe.py --list
   macOS:    ./.venv/bin/python transcribe.py --list

   Output example:
   [ 1] pending  my_class_lecture.mp4
   [ 2] pending  demo_video.mkv

2. TRANSCRIBE ONE VIDEO
   Pass the number from the list (or part of the filename):
   Windows:  .\.venv\Scripts\python transcribe.py 1
   macOS:    ./.venv/bin/python transcribe.py 1

3. TRANSCRIBE MULTIPLE VIDEOS (POWERSHELL LOOP)
   To transcribe videos 1 through 5 automatically:
   foreach ($n in 1..5) { .\.venv\Scripts\python transcribe.py $n }


WHAT YOU GET AFTER TRANSCRIBING
--------------------------------
Two files appear alongside your video:
  - VideoName.srt  : Subtitles file (VLC player loads this automatically)
  - VideoName.md   : Condensed readable text notes with timestamps per minute
